# data/ — набор из 18 кадров

Канонический набор: `01.jpg … 18.jpg` (все свои, ≤ 1280 px по длинной стороне, ≤ 184 КБ, JPEG, без EXIF-поворота).
**`01–15` — кадры с листом, `16–18` — негативные** (правильный ответ программы — «не найдено»).

`corners.json` **полный**: 18 ключей = 18 файлам, 15 кадров с четырьмя парами `[x, y]`, три негатива — `null`.
Углы проверены: все координаты внутри кадра, все 15 четырёхугольников выпуклые, площадь 30–73 % кадра.
Разметка сделана кликами в ноутбуке (`annotate`), координаты — в пикселях тех файлов, что лежат здесь;
если пересжимать/менять размер **после** разметки, углы собьются.

## Про негативы

По условию нужны три типа: (1) листа нет, но есть прямоугольный предмет; (2) лист уходит за кадр двумя углами;
(3) на выбор — белый на белом / мятый / два листа. Закрыты все три:

- `16.jpg` — тип 1: чёткие углы ноутбука, но внутри не светлее, чем снаружи → `looks_like_paper` отсекает;
- `17.jpg` — тип 2: два угла за кадром, `quad_from_lines` требует все четыре угла внутри кадра;
- `18.jpg` — тип 3: у мятого листа нет четырёх длинных прямых.

Все три отклонены всеми тремя режимами, в том числе всеми 20 зёрнами RANSAC (`hough_ok_of_20 = 20` —
для негатива «успех» означает корректный отказ). Доснимать ничего не нужно.

## Команды

Полный список — в `REPORT.md`, раздел 5. Основное:

```bash
python docscan.py annotate data/*.jpg --ann data/corners.json          # разметка (уже сделана)
python docscan.py eval data --ann data/corners.json --seeds 20 --canny 35,105 \
    --csv out/eval.csv --overlays out/eval
python docscan.py scan data/03.jpg --corners 7.4,708.2,549.1,198.0,945.5,571.1,350.3,1122.4 \
    --turn 1 -o out/03_scan.jpg --bw out/03_bw.png
```

## Мелочи

- Многие кадры сняты портретно, а лист лежит альбомно (`04`, `06`, `13`, `14`, `15`) — для `scan`
  понадобятся `--turn 1` / `--turn 3` и, если лист альбомный, `--aspect 1.414`.
- `sample_data/` — кадры курса, **не часть набора**: они нужны только для сверки реализации (`REPORT.md` §1.3).
- Исходные загрузки с длинными именами (`…542494…jpg`) были перенесены сюда и переименованы; дубли удалены.
- Свои фото только здесь: стоки, интернет и кадры курса вместо своих — −10 баллов.
